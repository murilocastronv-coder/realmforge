# Changelog

All notable changes to RealmForge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2025-04-11

### Added
- Isometric world rendering with 3D depth edges and 8 terrain biomes
- Animated water tiles with phase-offset shimmer
- Procedural world generation using Perlin noise
- WebSocket multiplayer with server-authoritative movement
- Player authentication (register/login)
- 4 character classes with unique skill trees
- Real-time combat with auto-attack and 6-slot skill hotbar
- Procedural enemy ranks (Normal, Champion, Elite, Boss)
- Full inventory, equipment, and bank systems
- Crafting system with recipes
- Player marketplace for trading
- 15+ quests with quest tracker
- Guild system with ranks and management
- Enchanting and item upgrade system
- Pet companions, fishing, and mining professions
- Arena PvP and dungeon finder
- Multi-channel chat (global, local, whisper, trade)
- Party system with invites
- Day/night cycle and weather system
- Emote wheel and NPC dialogue
- Achievement system and leaderboards
- Bestiary, factions, blessings, bounties, and rune crafting
- Kenney CC0 sprite assets (Tiny Dungeon, Tiny Town, RPG Urban)
- Preact HTML overlay UI with Tailwind CSS
